## Decisions Made
- Arrow IPC stream format chosen over pickle protocol 5 because PyArrow types only implement `__reduce__`, not `__reduce_ex__` with PickleBuffer support -- pickle p5 out-of-band buffers never fire for Arrow objects
- memoryview cast from signed (`b`) to unsigned (`B`) format required for assigning Arrow buffer data into shared memory (different buffer format specifications)
- Type tag stored as single byte immediately after the FSHR header, before IPC data, for minimal overhead

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Arrow buffer memoryview format mismatch with shared memory**
- **Found during:** Task 2
- **Issue:** `pa.Buffer` memoryview has format `b` (signed byte) while shared memory memoryview has format `B` (unsigned byte), causing `ValueError: memoryview assignment: lvalue and rvalue have different structures`
- **Fix:** Cast Arrow buffer memoryview via `memoryview(ipc_buf).cast("B")` before writing to shared memory
- **Files modified:** src/fastshare/_serializer.py
- **Verification:** All four Arrow types round-trip correctly through shared memory
- **Committed in:** 04c62b2 (Task 2 commit)
